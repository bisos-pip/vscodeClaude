** Scope of this panel is bisos.vscodeClaude: the command-line interfaces to the local VS Code
** and its Claude Code extension --- vscode.cs, vscodeClaude.cs and vscode-sbom.pcs.
** Layer 2 of the AI-Activity layers (VS Code, with Claude), plus the Python of layers 3 and 4:
** vscode_csu (VS Code itself), vscodeEmacs_csu (the partner Emacs), vscodeClaude_csu (the sessions).
** No editor needed: pure VS Code use runs these from a shell. Blee's vscode-claude is layered over it.
** See  [[elisp:(blee:bnsm:panel-goto "/bisos/panels/bisos-core/bisos-pip/bisos.vscodeClaude/README")][README]] of this bisos-pip package.
