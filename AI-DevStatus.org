- =py3/bin/vscodeClaude.cs=: CSXU over =vscodeClaude_csu= (layer 4), which imports the two below it.
- =py3/bin/vscode-sbom.pcs=: VS Code from Microsoft's apt repository; the local extensions, pinned.

* Key Design Decisions
- One package for every command-line interface to VS Code: layer 2 plus the Python of layers 3 and 4,
  kept apart as modules (vscode_csu names neither Emacs nor Claude; vscodeEmacs_csu no Claude).
- Python name =vscodeClaude= (the Blee package keeps =vscode-claude=).
- vscode-sbom.pcs installed on PATH with the package (the scripts dblock includes .pcs).
- Snippets that run outside the shell (the task, the hooks) name sys.executable and absolute paths:
  VS Code from the desktop has no BISOS venv on PATH; programPath skips relative PATH entries.
- The key is Ctrl+K Ctrl+E (--key to change it): Ctrl+Alt+E does not reach VS Code over VNC.
- The capability is induct (no service), materialized as the VS Code user (the assemble refuses
  root), leaf in collective/induct (Mohsen, 2026-11-01).
- Pointers outside this repo's import chain: the leaf in bro_rawBisos and its row in bxGenesis/start
  rawBisosCBMs/README.org (4.1); a critique of the whole stack in blee/vscode-claude NextSteps.org.
